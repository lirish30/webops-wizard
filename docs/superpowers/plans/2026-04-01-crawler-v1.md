# Crawler V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a `crawler` connector that seeds from sitemap-backed URLs, respects robots rules, crawls HTML pages with bounded depth, extracts page metadata, and stores per-page snapshots including raw HTML bodies.

**Architecture:** Implement crawler v1 as a dedicated worker connector under the existing integration sync framework. Keep crawl orchestration split into focused units for seeding, rules, robots evaluation, HTML fetch/extraction, and persistence so the current HTML path can be tested independently and later extended with a rendered fetch engine.

**Tech Stack:** TypeScript, Vitest, Prisma, worker connector framework

```ts
export function createCrawlerConnector(): ConnectorModule {
  return {
    provider: "crawler",
    oauth: {
      async refreshAccessToken() {
        throw new ConnectorExecutionError("Crawler connector does not use OAuth", {
          code: "OAUTH_UNSUPPORTED",
          retryable: false
        });
      }
    },
    async sync({ connection, now }) {
      if (!connection.propertyId) {
        throw new ConnectorExecutionError("Crawler sync requires a property binding", {
          code: "MISSING_PROPERTY_BINDING",
          retryable: false
        });
      }

      return {
        fetchedAt: now,
        latestDataAt: null,
        segments: []
      };
    }
  };
}
```
